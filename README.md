# XChenger Скинченжер для csgo_gc от Mikkokko
1) Скачать csgo_gc от Mikkokko руководство (https://steamcommunity.com/sharedfiles/filedetails/?id=3679849420)
2) установить скинченджер от меня на странице реализа (https://github.com/zxckostyatt-web/XChenger/releases/tag/TEST)
3) дождатся установки соединение с api (https://raw.githubusercontent.com/ByMykel/CSGO-API/refs/heads/main/public/api/en/skins.json)
5) выключить игру а то будет ошибка
6) выбрать скины
7) вкючить игру и проверить
8) радовотся))
